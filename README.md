# Python Module 1

A set of beginner Python exercises built around a garden theme, covering functions, user input, conditionals, loops, recursion and type hints.

## Exercises

| Function                        | Concept Practiced                                      |
|----------------------------------|---------------------------------------------------------|
| `ft_hello_garden()`              | Basic function and output                                |
| `ft_plot_area()`                 | User input and arithmetic                                 |
| `ft_harvest_total()`             | Multiple inputs and sum                                   |
| `ft_plant_age()`                 | Conditional statements (`if` / `else`)                    |
| `ft_water_reminder()`            | Conditional statements based on input                     |
| `ft_count_harvest_iterative()`   | Iteration with `for` and `range`                           |
| `ft_count_from_one_to_num(num)`  | Recursion                                                  |
| `ft_count_harvest_recursive()`   | Recursion driven by user input                             |
| `ft_garden_summary()`            | Mixed input types and formatted output                     |
| `ft_seed_inventory(seed_type, quantity, unit)` | Function parameters, type hints and multiple branches |

## Getting Started

### Requirements
- Python 3.8 or later

### Clone the repository

```bash
git clone git@github.com:Torph-10/python_module_1.git
cd python_module_1
```

### Run an exercise

Each exercise is a standalone function. Import and call it from a Python shell or a small script:

```python
from exercise_file import ft_plot_area

ft_plot_area()
```

Replace `exercise_file` with the actual file name containing the function.
